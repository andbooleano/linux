# Linux Troubleshooting

Registo de problemas, bugs e soluções encontrados
no dia a dia a trabalhar com Linux.

## Categorias

- [Networking](networking/README.md)
- [System](system/README.md)
- [Packages](packages/README.md)
- [Drivers](Drivers/README.md)
- [Boot](boot/README.md)

## Objetivo

Documentar problemas reais, comandos de diagnóstico,
causas raiz e soluções testadas.

## Formato dos registos

Cada problema deve incluir:
- Descrição do erro
- Distribuição e versão
- Logs relevantes
- Diagnóstico
- Solução
- Referências úteis
